# Arun Kumar Rana — .NET Full Stack Developer Portfolio

Professional, modern, responsive, and information-dense portfolio website showcasing 4+ years of enterprise software development experience with **.NET, C#, SQL Server, REST APIs, and Modern Web Interfaces**.

## 🌐 Live Website
[https://arunkrana5.github.io/](https://arunkrana5.github.io/)

---

## 🚀 Key Features

- **Modern SaaS Design Language**: Inspired by developer tools (Linear, Vercel, Supabase) with clean typography, compact cards, subtle borders, and zero clutter.
- **Information-Dense UI**: Designed for recruiters & engineering managers to evaluate skills, projects, and architecture within 10-15 seconds.
- **Responsive Across Devices**: Fully responsive layouts optimized for mobile (320px+), tablet, laptop, and 4K displays.
- **Dark / Light Mode**: Built-in theme switcher with `localStorage` persistence and system theme detection.
- **Interactive Case Study Modals**: In-depth project breakdown including problem statement, solution, architecture, tech stack, and contribution.
- **Architecture Pipeline**: Visual breakdown of backend API pipelines, database query optimization, security, and full SDLC execution.
- **Zero Heavy Dependencies**: Pure HTML5, CSS Variables, and Modular Vanilla JavaScript — lightning fast load times, zero build steps required.

---

## 🛠️ Technology Stack

- **Backend / Core**: C#, .NET Core, ASP.NET MVC, Web API, Entity Framework Core, Dapper ORM
- **Database**: SQL Server, T-SQL, Stored Procedures, Indexing & Query Tuning
- **Frontend**: HTML5, CSS3 Variables, ES6 JavaScript, AJAX/Fetch
- **Architecture**: SOLID Principles, Clean Architecture, Repository Pattern, RESTful API Design, RBAC
